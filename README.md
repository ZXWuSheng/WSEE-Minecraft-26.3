# 无声无息：拓展附魔（Without a sound: Expanded Enchantments）

适用于 Minecraft 26.3 的 Fabric / NeoForge 模组，当前版本为 WSEE 0.1.1。提供 31 项自定义附魔，覆盖剑、斧、矛、三叉戟、弓、弩、镐、钓鱼竿、盾牌、重锤及盔甲；本仓库当前维护 NeoForge，Fabric 暂缓同步本轮修复。

## 构建

使用 Java 25，在对应加载器的项目目录执行 `./gradlew clean build`（Windows 使用 `./gradlew.bat clean build`）。NeoForge 产物为 `build/libs/WSEE-0.1.1-NeoForge.jar`，Fabric 产物为 `build/libs/WSEE-0.1.1-Fabric.jar`。将匹配加载器的产物复制到游戏实例的 `mods/` 目录。

当前仅验证 NeoForge：构建包含 Java 回归检查，静态资源与运动接线检查分别运行 `python scripts/check_regression_baseline.py` 和 `python scripts/check_movement_contract.py --neoforge-only`。游戏客户端由用户手动启动。

## 玩法规则

所有自定义附魔都通过数据定义和服务端校验限制适用装备。剑气发射向前移动的波纹；盾击拥有独立的 50 tick 冷却；落星和震环只在有效的重锤猛击后触发。三叉戟附魔只作用于投出的 `minecraft:trident` 实体。飞钩命中方块碰撞面或活体实体后自动收绳，直接将玩家拉向挂点；再次使用钓鱼竿取消并回收。完整等级数值、冲突、双加载器安装要求和测试指令见 [详细规格](WSEE-0.1.1-Minecraft-26.3-Fabric-NeoForge-详细规格.docx)。

## 二段跳与飞钩

装备二段跳靴子并真正落地后，可在离地期间额外跳跃一次。松开并再次按下绑定的跳跃键，服务端授权向当前速度叠加一次基础冲量 `(0, 0.65, 0)`，下坠时额外抵消最多 0.25 格/tick 的下降速度。水平惯性、疾跑状态和原有上升速度保留；长按和重复请求不能增加使用次数。保留原有规则：触发时清零坠落距离，摔落伤害阈值增加两格。藤蔓和梯子不会吞掉已有跳跃机会或压低二段跳上升速度；接触它们不会刷新次数。二段跳没有准星指示器。

飞钩只有 I 级，使用原版钓鱼竿的 32 格距离限制，保留 1.15 倍发射速度，飞行受原版重力影响，形成抛物线。首次使用钓鱼竿发射钩头，命中真实方块碰撞面或活体实体后固定挂点并自动收绳牵引玩家。再次使用则取消并回收；未命中时再次使用也会直接回收，到达锚点附近后自动回收。长按发射键不会因自动重复而取消，需松开后再次按下；取消请求跨越命中时刻也有效，但不能影响下一次新抛出的鱼钩。钩头绑定首次发射时的持竿手。命中检测同时使用中心射线和真实鱼钩碰撞箱，覆盖方块边缘和半砖；无碰撞形状的草、花、藤蔓不作为锚点。固定锚点同步清除旧插值，避免钩头抖动。

收绳时直接朝挂点移动，水平运动对准挂点，避免绕点摆动；保留高于牵引目标的当前向上速度，因此二段跳不会被下一次牵引压掉。接近挂点时降低目标速度，移动遵循原版重力和碰撞。允许首次移动和原版上台阶；向下抛竿时，脚下地面不会误阻止水平牵引。接触方块面并确认拉力方向的移动被挡住时停止，另保留受阻且连续十个 tick 无进展的退出规则。实体锚点跟随目标，不造成伤害或拖拽目标。取消后保留结束瞬间的自然速度。收绳期间可二段跳，跳跃不会重置飞钩，飞钩清理也不会刷新跳跃次数。

| 运动参数 | 默认值 |
| --- | --- |
| 二段跳向上速度增量 | 基础 0.65 格/tick，下坠时额外补偿最多 0.25 格/tick |
| 基础牵引速度 | 0.594 格/tick，已有向上运动可超过此值 |
| 锚点到玩家碰撞箱的到达间距 | 1.5 格 |
| 1.5 格到达边界外的减速区域 | 3 格 |
| 接近锚点时最低速度系数 | 0.5，速度系数由 1 逐步减小 |
| 最长收绳时间 | 120 tick |
| 受阻且连续无进展的兜底阈值 | 10 tick |

飞钩参数位于 [`MovementMath.java`](src/main/java/cn/wusheng/oatz/movement/MovementMath.java)，二段跳增量是 [`DoubleJumpController.java`](src/main/java/cn/wusheng/oatz/movement/DoubleJumpController.java) 中的 `VERTICAL_IMPULSE`。飞钩距离保持原版的 32 格。锚点验证不会强制加载区块；死亡、退出、切换维度、失去装备资格、钩头或锚点消失、骑乘、鞘翅滑翔、创造飞行都会清理飞钩。保留原有坠落距离规则：收绳时清零，结束时恢复为收绳前保存值与当前值中的较大者。不带飞钩的钓鱼竿仍使用原版钓鱼及空军逻辑；飞钩收绳不会产生渔获。飞钩与饵钓、海之眷顾、空军冲突。

当前 NeoForge 的同步规则：服务端验证资格和挂点，每 tick 通过 FlyingHookPullPayload 授权一次直接牵引目标，包含玩家、维度、会话 UUID、递增序号及当前钩头 UUID。客户端验证当前自身和钩头，和二段跳共用运动序号去重，再读取当时真实速度执行一次牵引；不保存持续预测力，不发送旧的全量原版速度包，也不清除外部运动同步标志。水平速度由直接牵引控制，已有高于牵引目标的 Y 速度完整保留。二段跳继续独立通过 MovementImpulsePayload 授权一次 0.65 向上冲量及最多 0.25 的下坠补偿；客户端按接收时实际下坠速度缩小补偿，只执行一次，不受飞钩目标速度限制。钩头与绳索继续同步显示。构建及回归检查不能替代游戏内手感验证。验收场景包括静止、疾跑、上升、下落、受外力时二段跳，墙面及半砖锚定，正面和斜向收绳，收绳中二段跳，取消及锚点破坏，以及两个加载器的普通钓鱼和空军。
