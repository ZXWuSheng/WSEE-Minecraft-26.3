# 无声无息：拓展附魔（Without a sound: Expanded Enchantments）

适用于 Minecraft 26.3 的 Fabric / NeoForge 模组，当前版本为 WSEE 0.1.1。提供 31 项自定义附魔，覆盖剑、斧、矛、三叉戟、弓、弩、镐、钓鱼竿、盾牌、重锤及盔甲；两个加载器使用相同的玩法规则。

## 构建

使用 Java 25，在对应加载器的项目目录执行 `./gradlew clean build`（Windows 使用 `./gradlew.bat clean build`）。NeoForge 产物为 `build/libs/WSEE-0.1.1-NeoForge.jar`，Fabric 产物为 `build/libs/WSEE-0.1.1-Fabric.jar`。将匹配加载器的产物复制到游戏实例的 `mods/` 目录。

## 玩法规则

所有自定义附魔都通过数据定义和服务端校验限制适用装备。剑气发射向前移动的波纹；盾击拥有独立的 50 tick 冷却；落星和震环只在有效的重锤猛击后触发。三叉戟附魔只作用于投出的 `minecraft:trident` 实体。飞钩命中方块碰撞面或活体实体后固定，等待再次使用钓鱼竿才开始收绳，并向当前速度叠加牵引加速度。完整等级数值、冲突、双加载器安装要求和测试指令见 [详细规格](WSEE-0.1.1-Minecraft-26.3-Fabric-NeoForge-详细规格.docx)。

## 二段跳与飞钩

装备二段跳靴子并真正落地后，可在离地期间额外跳跃一次。松开并再次按下绑定的跳跃键，服务端会向当前速度叠加一次 `(0, 0.65, 0)`。水平惯性、疾跑状态、原有上升或下落速度及外部推力均保留；长按和重复请求不能增加使用次数。保留原有规则：触发时清零坠落距离，摔落伤害阈值增加两格。

飞钩只有 I 级，使用原版钓鱼竿的 32 格距离限制，保留原有的 1.15 倍发射速度和无重力飞行。首次使用钓鱼竿发射钩头，命中真实方块碰撞面或活体实体后固定，此时不会自动拉动玩家。再次使用开始持续收绳；牵引期间再使用一次则取消并回收。未命中时再次使用会直接回收，到达锚点附近后自动回收。钩头绑定首次发射时的持竿手。

收绳逐步缩短目标绳长。绳索松弛时不施加拉力，绷紧后向当前速度叠加有限的朝向锚点加速度，保留切向惯性和外部推力。接近锚点时降低拉力，移动遵循原版碰撞；受阻且连续十个 tick 无法接近锚点时结束。实体锚点跟随目标，不造成伤害或拖拽目标。取消后保留结束瞬间的自然速度。收绳期间可二段跳，跳跃不会重置飞钩，飞钩清理也不会刷新跳跃次数。

| 运动参数 | 默认值 |
| --- | --- |
| 二段跳向上速度增量 | 0.65 格/tick |
| 收绳速度 | 0.35 格/tick |
| 最大牵引加速度 | 0.24 格/tick² |
| 飞钩提供的朝向锚点速度上限 | 0.55 格/tick |
| 锚点到玩家碰撞箱的到达间距 | 1.5 格 |
| 1.5 格到达边界外的减力区域 | 3 格 |
| 接近锚点时最低张力系数 | 0.5，减力系数由 1 逐步减小 |
| 最长收绳时间 | 120 tick |
| 受阻且连续无进展的结束阈值 | 10 tick |

飞钩参数位于 [`MovementMath.java`](src/main/java/cn/wusheng/oatz/movement/MovementMath.java)，二段跳增量是 [`DoubleJumpController.java`](src/main/java/cn/wusheng/oatz/movement/DoubleJumpController.java) 中的 `VERTICAL_IMPULSE`。飞钩距离保持原版的 32 格。锚点验证不会强制加载区块；死亡、退出、切换维度、失去装备资格、钩头或锚点消失、骑乘、鞘翅滑翔、创造飞行都会清理飞钩。保留原有坠落距离规则：收绳时清零，结束时恢复为收绳前保存值与当前值中的较大者。不带飞钩的钓鱼竿仍使用原版钓鱼及空军逻辑；飞钩收绳不会产生渔获。飞钩与饵钓、海之眷顾、空军冲突。

两个加载器均由服务端验证资格并授权运动增量。客户端收到授权后，将增量叠加到接收时的自身实际速度，按当前玩家、维度、会话和递增序号校验并去重；输入时不预测运动，也不自行决定资格。牵引使用服务端接受的运动记录估算径向速度，只发送本次拉力的差额，避免全量速度包覆盖客户端惯性。服务端同时给正向牵引增量附带径向速度上限；客户端只按接收时的实际速度缩小这一次授权增量，已有速度超过上限时保留原速度、不再追加，切向速度不变。接近锚点时只减少新增拉力，完整保留已有速度；由原版重力、阻力、碰撞和到达回收自然结束运动。二段跳不使用该正向限速，这只是执行服务端授权的保守幅度，不是客户端自行判定资格或持续预测牵引。钩头与绳索继续同步显示。构建及回归检查不能替代游戏内手感验证。验收场景包括静止、疾跑、上升、下落、受外力时二段跳，墙面及半砖锚定，正面和斜向收绳，收绳中二段跳，取消及锚点破坏，以及两个加载器的普通钓鱼和空军。
